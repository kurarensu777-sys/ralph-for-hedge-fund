# Law - the shelf

The law's long form, kept by the fund agent. The base prompt (the root `CLAUDE.md`) is the short
form every agent loads; these five books are what it points to. A lesson true of the whole fund
is a new `##` chapter in one of them, opening with its `Read when:` line.

| Book | Read when |
|---|---|
| `how-we-work.md` | about to write outside your folder, file a board item, sync, land, touch data or a credentialed door, edit settings, file a lesson or close a session, start a turn of more than about three steps, relay a message to a workflow agent, or run a job longer than ten minutes |
| `how-we-know.md` | about to conclude anything from a number, call a re-run a replication, or write or trust a check |
| `the-lab-loop.md` | about to run a lab desk, pre-register, record, read a fixed-age result or hold a retro |
| `how-we-guard.md` | about to pull, keep, pin or delete data, touch a broker's gateway or a logged-in data session, or edit or apply a change to the deny list |
| `how-we-write.md` | about to write or rewrite anything a person reads: a reply, a report, a commit message, a board item, a chapter |

| Series | What it holds |
|---|---|
| `the-annals/` | the fund's eras, era by era (the Git room's Eras band reads them) |
| `the-atlas/` | `pipeline.json` and `data-flow.json`, read by the Map room |
