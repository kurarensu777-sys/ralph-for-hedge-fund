# The cockpit's own shelf

real miss; none is a preference. A lesson true of the whole fund belongs in `app/library/law/`.

| Book | Read when |
|---|---|
| `cockpit-ui.md` | about to change a room, open a stream, render a reading, drive the running cockpit from an agent's browser, or call a UI change verified; or a page does nothing while curl works |
| `cockpit-server.md` | about to add state or a config file, restart fundd (from a seat too), change how long an agent process stays open, change what boots an agent, or land a branch; or a board item will not start, you are handing work to another agent, you are about to set the floor STOP switch, the board CLI said fundd did not answer, or you are writing a scratch script that imports the app tree |
